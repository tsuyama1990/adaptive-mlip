# PyAceMaker

PyAceMaker is an Intent-Driven platform for automating the generation of Adaptive Machine Learning Interatomic Potentials (MLIPs). It leverages MACE, LAMMPS, and Quantum ESPRESSO to construct highly accurate potentials iteratively using active learning, directly from a visual representation of your simulation goals.

## Features

- **Automated Active Learning**: Constructs datasets via intelligent sampling of MD trajectories where models exhibit high uncertainty.
- **Visual Intent Compiler**: Translates visual node-based Directed Acyclic Graphs (DAGs) into mathematically rigorous simulation configs.
- **Robust Preflight Diagnostics**: Sub-second validation checks catch structural collisions, syntax errors, and missing dependencies before dispatching computationally expensive jobs.
- **FastAPI Telemetry**: Streams simulation state and metrics in real-time via websockets.

## Installation

Ensure you have Python 3.11+ installed. We recommend using `uv` for lightning-fast dependency management:

```bash
# Clone the repository
git clone <repository_url>
cd pyacemaker

# Sync the environment
uv sync
```

## Usage

You can start the backend API server using the following command:

```bash
uv run uvicorn pyacemaker.main:app --host 0.0.0.0 --port 8000
```

Once running, the API accepts `IntentRequest` payloads generated by the visual GUI at `/api/v1/intent/compile` for semantic compilation and preflight validation.

For example, to compile a basic active learning workflow for Aluminium using a slider configuration via HTTP:

```python
import requests

payload = {
    "accuracy_speed_slider": 5, # 1=Speed, 10=Accuracy
    "target_material": "Al",
    "nodes": [
        {
            "id": "node_1",
            "type": "INITIAL_STRUCTURE",
            "data": {
                "type": "INITIAL_STRUCTURE",
                "chemical_symbol": "Al",
                "lattice_constant": 4.05
            }
        },
        {
            "id": "node_2",
            "type": "ACTIVE_LEARNING_LOOP",
            "data": {
                "type": "ACTIVE_LEARNING_LOOP"
            }
        }
    ],
    "edges": [
        {"source": "node_1", "target": "node_2"}
    ],
    "advanced_settings": {}
}

response = requests.post("http://127.0.0.1:8000/api/v1/intent/compile", json=payload)
print(response.json())
```

You can also run pre-configured scenarios using the CLI:
```bash
uv run pyacemaker --scenario my_scenario.yml
```

## Project Structure

```text
src/pyacemaker/
├── api/           # FastAPI routers and websocket endpoints
├── core/          # Business logic: Orchestrator, Active Learning loop, Preflight Diagnostics
├── domain_models/ # Pydantic schemas enforcing strict design-by-contract interfaces
├── interfaces/    # Drivers wrapping LAMMPS, Quantum ESPRESSO, and EON
├── scenarios/     # Pre-packaged YAML configurations for common workflows
└── utils/         # Extraction algorithms, math helpers, and path validators
```
